# Evidencias de la práctica 2

`software-validation.md` registra las verificaciones de escritorio ejecutadas.
Las plantillas CSV tienen únicamente cabeceras y se completarán con datos reales.

Guardar aquí fotografías del montaje, capturas de señales, videos, CSV y logs
seleccionados. Anotar fecha, versión del código, método y condiciones de cada prueba.
Los logs temporales de `logs/` están ignorados por Git; copiar solamente los que
sean pertinentes para respaldar la entrega. Evitar incluir credenciales WiFi.

Seguir [validation.md](../validation.md) para exactitud, muestreo, respuesta y
estabilidad. Un archivo vacío o una simulación no demuestra un requisito físico.
